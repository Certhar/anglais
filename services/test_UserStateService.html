Tests UserStateService — extension progression par mot

⚠️ Avant tout : ces tests écrivent dans la clé vocabulaire.userState.v1 de localStorage et la nettoient entre chaque test. Si tu as déjà des données dans cette clé pour l'app Vocabulaire, sauvegarde-les avant de lancer (DevTools → Application → Local Storage → copier la valeur).
Comment lancer cette page — les modules ES6 ne marchent pas en file://. Sers le dossier avec un petit serveur : 
cd dossier_du_test
python3 -m http.server 8000
# puis ouvre http://localhost:8000/test_UserStateService.html
Ou avec node : npx serve.
