# Comment lire les prononciations dans la liste

Avant de commencer le vocabulaire, voici les **règles de lecture** des prononciations entre crochets dans le tableau. Toutes les prononciations sont données en anglais britannique (BBC, Harry Potter, Peppa Pig).

La règle générale : **tout ce qui n'est pas marqué se lit comme en français.** On a juste ajouté quelques symboles pour les sons qui n'existent pas en français.

---

## Les sons spéciaux à apprendre

### Le schwa : `ə`

Le son le plus fréquent de l'anglais. Voyelle complètement relâchée, bouche au repos. C'est presque un "e" de "petit" mais encore plus mou.

- about → `ə-bawt`
- sister → `sis-tə`
- a book → `ə bùk`

### Le `ø`

Entre "eu" et "a". Bouche ouverte vers l'arrière, plus relâchée que le "eu" de "peu".

- mother → `mø-dhə`
- love → `løv`
- cup → `køp`

### Le `th`

Pointe de la langue **entre les dents**, on souffle. Pas de vibration. C'est un son spécifique à l'anglais.

- think → `thinnk`
- three → `thrî`
- bath → `bâth`

### Le `dh`

Même position que `th` (langue entre les dents) mais avec vibration des cordes vocales. **Surtout pas un Z français.**

- this → `dhis`
- mother → `mø-dhə`
- father → `fâ-dhə`

### Le `h`

Le `h` anglais se prononce ! C'est un souffle expiré, comme quand on est essoufflé.

- hello → `hè-lô`
- house → `haws`
- hot → `hòt`

### Le `ng`

Son nasal en fin de mot. La langue ne touche **rien** à l'avant : tout se passe à l'arrière de la bouche.

- sing → `sing`
- king → `king`
- thing → `thing`

Quand un `n` est suivi de `k` ou `g` à l'écrit, on prononce déjà naturellement ce son en français (essaie : "un kilo" → "ung-kilo"). Donc on garde simplement `n` dans la prononciation : `thinnk`, `drinnk`.

### Le `w`

Comme le "w" de "wagon" en français, ou le début de "oui" prononcé vite.

- water → `wô-tə`
- what → `wat`
- well → `wèl`

### Le `r`

⚠️ **Le `r` ne se prononce que lorsqu'une voyelle suit.** En fin de mot, ou avant une consonne, il **disparaît** complètement.

- red → `rèd` (r prononcé)
- very → `vè-ri` (r prononcé)
- car → `kâ` (r muet !)
- sister → `sis-tə` (r muet !)
- bird → `beud` (r muet !)

C'est la marque de l'anglais britannique. Les Américains, eux, prononcent tous les r.

## Les voyelles avec accent

On utilise les accents pour distinguer **brèves** et **longues**, ou ouvertes et fermées.

| Accent grave (bref) | Accent circonflexe (long) | Comparaison |
|---|---|---|
| `à` (cat → `kàt`) | `â` (car → `kâ`) | court / long |
| `ì` (ship → `chìp`) | `î` (sheep → `chîp`) | court / long |
| `ù` (book → `bùk`) | `û` (food → `fûd`) | court / long |
| `ò` (dog → `dòg`) | `ô` (door → `dô`) | court / long |
| `è` (bed → `bèd`) | — | e ouvert |

⚠️ **Attention au `ô`** : c'est un O **ouvert** et long (comme dans "fort" allongé), **pas** le O fermé de "dôme". Si tu prononces `dô-tə` (daughter) avec un O fermé, tu sonneras écossais.

## Les diphtongues (deux voyelles enchaînées)

Une diphtongue, c'est deux voyelles fondues en **une seule syllabe**.

| Notation | Exemples |
|---|---|
| `aï` | time → `taïm`, my → `maï`, child → `tchaïld` |
| `aw` | now → `naw`, house → `haws`, mouth → `mawth` |
| `oï` | boy → `boï`, oil → `oïl` |
| `éï` | cake → `kéïk`, day → `déï`, name → `néïm` |
| `ô` | go → `gô`, no → `nô`, home → `hôm` |

---

## Les semi-consonnes

Le `y` joue le même rôle que dans "yaourt" ou "voyage" : c'est un glissement vers la voyelle suivante, pas une syllabe à part.

- yes → `yès`
- you → `yû`
- music → `myû-zik`
- cute → `kyût`

Idem pour `w` (déjà vu plus haut).

## Quelques paires minimales pour s'entraîner

Lis à voix haute en exagérant la différence :

- ship `chìp` / sheep `chîp`
- cat `kàt` / cut `køt` / car `kâ`
- think `thinnk` / sink `sinnk`
- this `dhis` / zip `zip`
- bed `bèd` / bad `bàd`
- live `lìv` (verbe) / leave `lîv`
- full `fùl` / fool `fûl`
- not `nòt` / note `nôt`
